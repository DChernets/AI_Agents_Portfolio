# Industrial Automation - проверка договоров и проектной документации

**AI-assisted система автоматизации документооборота для промышленных инженерных проектов.**

---

## Обзор

Industrial Automation помогает инженерным компаниям сокращать ручную работу при проверке договоров, технической документации и проектных материалов. Система объединяет детерминированные правила, парсинг документов, OCR и LLM-анализ с обязательными точками human approval.

Решение рассчитано на промышленные проекты, где важны точность, трассируемость и конфиденциальность, а не полностью автономные решения без инженера.

---

## Модули

### Contract Review
Автоматическая проверка договора заказчика по внутренним шаблонам и risk rules:
- сравнивает проект договора заказчика с предпочтительными формулировками компании;
- выявляет юридические, коммерческие, поставочные, гарантийные, IP и liability риски;
- генерирует протокол разногласий;
- предлагает альтернативные формулировки и коммерческое обоснование;
- отмечает, какие пункты требуют проверки юриста, финансиста, коммерческого директора или руководства.

### Project Documentation Validation
Проверка непротиворечивости проектной документации:
- обрабатывает PDF, DOCX, XLSX и данные, извлеченные из DWG;
- сверяет разделы ЭМ, АТХ, ТХ/P&ID;
- находит расхождения в KKS-кодах, кабелях, сигналах, оборудовании, спецификациях и ревизиях;
- формирует таблицу замечаний с документом, страницей или листом;
- ранжирует замечания по критичности и предлагает действия инженеру.

---

## Ключевые возможности

- извлечение рисков из договоров;
- генерация протокола разногласий;
- проверка полноты исходных данных;
- реестр документов проекта;
- OCR и извлечение таблиц из технических документов;
- cross-document validation rules;
- CAD/PDF pipeline для текстов из чертежей;
- human approval workflow для юридических и инженерных решений;
- confidentiality-first модель обработки данных.

---

## Типовой workflow

```text
Входные документы
      |
      v
Parsing / OCR / table extraction
      |
      v
Structured project data and document registry
      |
      +--> Contract Review -> Протокол разногласий
      |
      +--> Documentation Validation -> Таблица замечаний
      |
      v
Human approval and final export
```

## Технологический стек

| Область | Технологии |
|---------|------------|
| Backend | Python 3.10+, async processing |
| Documents | PDF, DOCX, XLSX parsing |
| OCR | OCR pipeline для сканов и чертежей |
| AI | LLM-assisted analysis and explanation |
| Rules | Deterministic validation rules |
| Output | Word и Excel generation |
| Engineering data | KKS, кабельные журналы, спецификации, таблицы ревизий |

## Бизнес-эффект

- быстрее готовятся протоколы разногласий;
- раньше выявляются неполные исходные данные;
- меньше ручной сверки между проектными документами;
- лучше трассируются риски и несоответствия;
- появляется понятный approval flow для чувствительных юридических и технических решений.
