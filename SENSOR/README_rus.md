# SENSOR - AI-платформа для Telegram Intelligence

**Production SaaS для поиска лидов и диалогового поиска по Telegram-данным.**  
Сайт: [sensor-tg.tech](https://sensor-tg.tech)

---

## Обзор

SENSOR превращает Telegram-чаты и каналы в систему бизнес-аналитики: собирает сообщения, анализирует коммерческий спрос с помощью AI, находит квалифицированные лиды и строит поисковые базы знаний по истории Telegram.

---

## Основные модули

### SENSOR.Leads
AI-лидогенерация из Telegram-сообществ:
- мониторинг выбранных чатов, групп и каналов;
- определение коммерческого спроса через семантический AI-анализ;
- скоринг качества и срочности лида;
- доставка квалифицированных лидов в канал менеджера или bot-интерфейс;
- feedback-калибровка для улучшения качества будущих лидов.

### SENSOR.Chat
RAG-поиск по истории Telegram:
- сбор и индексация сообщений из чатов;
- вопросы на естественном языке по собранной истории;
- ответы с контекстом источников;
- Telegram-specific база знаний для сообществ и команд.

### Multi-tenant слой аккаунтов
- каждый пользователь подключает свой Telegram-аккаунт;
- авторизация через QR-код или телефон + код;
- шифрование Telegram-сессий;
- изоляция данных между пользователями;
- отдельные источники, чаты и lead-проекты для каждого пользователя.

## Бизнес-ценность

| Проблема | Решение SENSOR |
|----------|----------------|
| Ручной мониторинг пропускает спрос | AI постоянно анализирует обсуждения в Telegram |
| Ключевые слова дают много шума | Семантический анализ понимает контекст и намерение |
| Историю чатов сложно искать | RAG превращает сообщения в базу знаний |
| Нужно быстро реагировать на лиды | Квалифицированные лиды отправляются менеджерам |
| У клиентов должны быть отдельные данные | Multi-tenant архитектура разделяет сессии и данные |

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.10+ |
| Backend | FastAPI, asyncio |
| Telegram clients | Telethon, Pyrogram |
| Bot layer | python-telegram-bot |
| AI | Google Gemini |
| RAG | FileSearch / semantic retrieval |
| База данных | SQLite, PostgreSQL-ready architecture |
| Безопасность | Fernet encrypted sessions |
| Деплой | Linux VPS, systemd |

---

## Архитектура

```text
Telegram-аккаунт пользователя
        |
        v
QR / Phone Auth -> Encrypted Session Storage
        |
        v
Collector Manager -> Message Store -> AI Analysis
        |                              |
        |                              +-> SENSOR.Leads scoring and delivery
        |                              |
        +------------------------------+-> SENSOR.Chat indexing and RAG search
```
